## 🔍 Overview

CulinaryCloud is a full‑stack web application built with the MERN stack (MongoDB, Express, React, Node.js). It enables users to:

- 🔑 *Register & Authenticate*  
- 📖 *Create, Read, Delete* their own recipes  
- ⏳ *Real-time Walkthrough* of posted recipes  
- 🔎 *Search & Filter* by ingredients, cuisine, dietary tags  
- 🤖 *AI‑Powered Personalization* (GeminiAI) for recipe suggestions  
- 🍽 *Calorie & Nutrition Analysis* via external API  
- 💬 *Community Engagement* (likes, comments, ratings)  
- 🏆 *Badges & Achievements* for active contributors  

---

## 🚀 Features

1. *User Management*  
   - JWT‑based auth, bcrypt password hashing  
   - Profile editing, saved recipes  

2. *Recipe CRUD*  
   - Image/video uploads (AWS S3 / Cloudinary)  
   - Ingredient lists, step‑by‑step instructions  

3. *Real-time Walkthrough*  
   - Interactive, step-by-step cooking mode  
   - Users can progress through each recipe step without losing track  

4. *Search & Filters*  
   - By cuisine, ingredients, prep time, dietary tags  

5. *AI Recommendations*  
   - Personalized recipe feed powered by OpenAI  
   - Ingredient substitutions  

6. *Nutrition Insights*  
   - Calorie & macronutrient breakdowns  

7. *Community Module*  
   - Likes, comments, ratings  
   - Trending & Quick‑prep (<10 min) sections
